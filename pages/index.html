About

Quant.Infra.Net is a .NET quantitative trading infrastructure library that lets you fetch data, run statistical analysis, execute trades, and send notifications with minimal code.

Stop reinventing the wheel — focus on your strategy. Unified broker integrations (Binance Futures, Alpaca US Equity, Charles Schwab, Interactive Brokers via InterReact), built-in statistical analysis tools, notification services, and more.

Key Features

  • Data Acquisition — Yahoo Finance, Binance crypto klines, CSV/MySQL/MongoDB local data sources
  • Statistical Analysis — ADF stationarity test, OLS regression, Z-Score, Shapiro-Wilk normality test, pair-trading spread calculation
  • Trade Execution — Binance Futures (spot/order/liquidate), Alpaca US Equity, Charles Schwab equity/options, Interactive Brokers via TWS/Gateway
  • Notifications — DingTalk bot, WeChat Work webhook, personal/commercial bulk email
  • Performance Analytics — CAGR, Sharpe ratio, Calmar ratio, max drawdown, strategy performance analyzer
  • Utilities — IntervalTrigger, RollingWindow<T>, comprehensive unit test coverage
